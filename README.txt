NEW DAWN CARPET CLEANING - static website
=========================================
No build tools needed. Plain HTML + CSS + JavaScript.

  index.html        the page (all text lives here - edit with any text editor)
  404.html          "page not found" screen
  contact.php       emails the quote-form submissions (needs PHP hosting)
  css/style.css     styles (colors/fonts are variables near the top)
  js/main.js        small script: menu, scroll effects, sliders, form
  images/           all photos + logo

UPLOAD: put everything in the site's web root (public_html), keeping the folders.
You can also double-click index.html to preview it on your own computer
(the quote form only works once uploaded to a PHP host).
