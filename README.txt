NEW DAWN CARPET CLEANING - static website
=========================================
100% Static HTML + CSS + JavaScript. No server build tools or PHP required.

  index.html        the page (all text lives here - edit with any text editor)
  gallery.html      standalone photo & video gallery
  404.html          "page not found" screen
  css/style.css     styles
  js/main.js        client-side scripts: menu, scroll effects, lightbox, form
  images/           all optimized photos, videos & logo

QUOTE FORM (Web3Forms):
The form uses Web3Forms (https://web3forms.com) to deliver leads directly to email.
1. Get a free Access Key at https://web3forms.com (takes 10 seconds, enter your email).
2. Open index.html and find:
   <input type="hidden" name="access_key" value="YOUR_ACCESS_KEY_HERE">
3. Replace YOUR_ACCESS_KEY_HERE with your key.
